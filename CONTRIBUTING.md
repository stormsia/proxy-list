# Contributing to stormsia/proxy-list

Thank you for your interest in improving the proxy pool!

## How to Contribute
- **Submit New Public Sources:** Open an issue or submit a PR adding new reliable sources to our harvesting pipeline.
- **Report Dead Proxies / Issues:** Open an issue with details on unreachable nodes.
- **Hydra Engine:** For improvements to the validation engine, see [Hydra](https://github.com/stormsia/hydra).

## Code of Conduct
Please adhere to respectful communication in all interactions.
